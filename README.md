# Cachoeira Tracker

Este repositório contém o planejamento do sistema Cachoeira Tracker, desenvolvido com foco na organização de projetos utilizando metodologias ágeis, versionamento com Git e colaboração em equipe.

---

## 1. Visão Geral do Projeto

O Cachoeira Tracker é um sistema que permite aos usuários registrar visitas a cachoeiras, acompanhar seu desempenho em trilhas e interagir com outros usuários.

A proposta do sistema é incentivar atividades ao ar livre, promovendo saúde, lazer e integração social.

---

## 2. Objetivo do Sistema

* Incentivar a prática de atividades físicas ao ar livre
* Permitir o registro e acompanhamento de trilhas
* Criar um ambiente social entre usuários
* Aplicar conceitos de gamificação

---

## 3. Principais Funcionalidades

O sistema foi planejado com base nas seguintes funcionalidades:

| Categoria   | Funcionalidades                        |
| :---------- | :------------------------------------- |
| Usuários    | Cadastro, login, perfil                |
| Atividades  | Registro de trilhas, tempo e distância |
| Localização | Mapas, busca de locais                 |
| Social      | Feed, curtidas, ranking                |
| Segurança   | Botão de emergência, dicas             |

---

## 4. Tecnologias Utilizadas

| Tecnologia | Finalidade                    |
| :--------- | :---------------------------- |
| JavaScript | Desenvolvimento geral         |
| Node.js    | Backend                       |
| HTML/CSS   | Interface                     |
| GitHub     | Versionamento                 |
| Trello     | Organização das tarefas       |

---

## 5. Metodologia de Desenvolvimento

O projeto foi organizado utilizando a metodologia Scrum, com divisão em Sprints semanais e acompanhamento das tarefas por meio de um quadro Kanban.

---

## 6. Estrutura do Repositório

| Arquivo    | Descrição                   |
| :--------- | :-------------------------- |
| README.md  | Descrição geral do projeto  |
| Backlog.md | Lista de tarefas do sistema |
| Sprint.md  | Planejamento das Sprints    |
| (Nome).md  | Atividades individuais      |

---

## 7. Equipe

O projeto foi desenvolvido em grupo com divisão de papéis baseada em Scrum:

* Product Owner: responsável pelo backlog e prioridades
* Scrum Master: responsável pelo planejamento das Sprints
* Desenvolvedor(es): responsáveis pela execução das tarefas

---

## 8. Considerações

Este projeto tem como foco o planejamento e organização do desenvolvimento de software, não sendo necessário implementar o sistema nesta etapa.

O uso de ferramentas como GitHub e Trello permite melhor controle das atividades e colaboração entre os integrantes.
