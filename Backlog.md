# Backlog do Produto - Cachoeira Tracker

Este documento contém a listagem de todas as funcionalidades e tarefas planejadas para o sistema, organizadas por prioridade.

## Legenda de Prioridades:
* **Alta:** Essencial para o funcionamento básico (MVP).
* **Média:** Funcionalidades importantes de experiência do usuário.
* **Baixa:** Diferenciais e melhorias estéticas.

---

## 1. Gestão de Usuários e Acessos
| ID | Tarefa | Descrição | Prioridade |
| :--- | :--- | :--- | :--- |
| 01 | Tela de Splash | Criar tela inicial com o logo do projeto. | Baixa |
| 02 | Cadastro de Usuário | Formulário com Nome, E-mail e Senha. | Alta |
| 03 | Login/Autenticação | Integração com Firebase para acesso seguro. | Alta |
| 04 | Recuperação de Senha | Fluxo de "Esqueci minha senha" via e-mail. | Média |
| 05 | Perfil do Usuário | Exibição de foto, bio e estatísticas de trilhas. | Média |
| 06 | Edição de Perfil | Permitir que o usuário altere seus dados cadastrais. | Baixa |

## 2. Registro e Monitoramento de Trilhas
| ID | Tarefa | Descrição | Prioridade |
| :--- | :--- | :--- | :--- |
| 07 | Iniciar Atividade | Botão para começar o rastreamento via GPS. | Alta |
| 08 | Cronômetro | Marcar o tempo total de deslocamento. | Alta |
| 09 | Cálculo de Distância | Medir a quilometragem percorrida em tempo real. | Alta |
| 10 | Nível de Intensidade | Seletor para classificar a trilha (Leve/Moderada/Pesada). | Média |
| 11 | Finalizar Visita | Botão para encerrar o registro e salvar os dados. | Alta |
| 12 | Resumo da Visita | Tela com estatísticas finais após o encerramento. | Alta |

## 3. Mapas e Localização
| ID | Tarefa | Descrição | Prioridade |
| :--- | :--- | :--- | :--- |
| 13 | Integração de Mapa | Configurar mapa interativo para visualização. | Alta |
| 14 | Marcadores de Cachoeira | Exibir pontos de interesse próximos no mapa. | Alta |
| 15 | Busca de Locais | Barra de pesquisa por nome de cachoeira ou cidade. | Média |
| 16 | Trilhas Favoritas | Opção para salvar locais para visita futura. | Baixa |
| 17 | Clima em Tempo Real | Consultar condições meteorológicas do local. | Média |
| 18 | Fotos do Local | Upload de imagens da cachoeira visitada. | Média |

## 4. Gamificação e Social
| ID | Tarefa | Descrição | Prioridade |
| :--- | :--- | :--- | :--- |
